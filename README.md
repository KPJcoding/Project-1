Snake Game on STM32:
This project is an implementation of Embedded C using STM32 by replicating the famous 2D Snake game.  
This is my first project, so there might be inefficient code blocks and unorganized portions. 

Idea:
The project has STM32 connected to an external LCD Module using SPI Protocol. A Snake Game is then displayed on the screen where the snake can be controlled.
The Snake is controlled using buttons connected to the same STM32 Microcontroller board.

Components:
1.STM32 F446RE
2.1.8 Inch TFT LCD (128x160 pixels)
3.Breadboard and other connecting hardware
4.USB A to USB Mini B

How to run:
The files in the repository are STM32CubeIDE Project. So, STM32CubeIDE has to be downloaded to run these files.
